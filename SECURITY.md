# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please follow the steps below:

1. **Do not disclose the vulnerability publicly** until it has been addressed.
2. **Submit a private report** using one of the following methods:
   - Email: security@stellarlend.dev
   - Keybase: [stellarlend-security](https://keybase.io/team/stellarlend-security)
   - GitHub Security Advisory: [Submit a Security Advisory](https://github.com/Smartdevs17/stellarlend/security/advisories/new) (if accessible)

3. Include the following details in your report:
   - A clear description of the vulnerability.
   - Steps to reproduce the issue.
   - Potential impact of the vulnerability.
   - Any suggested fixes or mitigations.

## Bug Bounty Program

This project participates in a bug bounty program as outlined in our [Bug Bounty Policy](BUG_BOUNTY.md). Approved reports may be eligible for a payout in USDC.

### Payout Process
- Once a vulnerability is confirmed and fixed, the reporter will be contacted privately to provide a USDC wallet address.
- Payouts are made after the fix is deployed and verified.
- Payout amounts are determined based on the severity and impact of the vulnerability, as defined in the [Bug Bounty Policy](BUG_BOUNTY.md).

## Preferred Languages

Reports may be submitted in English.

## Response Time

The maintainers will acknowledge receipt of your report within 48 hours. You will receive updates on the progress of the fix and the expected timeline for resolution.

For urgent vulnerabilities (e.g., active exploits), include `[URGENT]` in the subject line of your report.
